# anqiwang02.github.io

Personal website and blog of Anqi (Anchie) Wang, built with Jekyll and hosted on GitHub Pages.

Live at [anqiwang02.github.io](https://anqiwang02.github.io).

## About

This site is built on the [Trophy](https://github.com/thomasvaeth/trophy-jekyll) Jekyll theme by Thomas Vaeth, customized with an About Me page (education, research, and teaching experience) and personal content.

## Development

Install dependencies with [Bundler](http://bundler.io/):

```
bundle install
```

Serve the site locally:

```
bundle exec jekyll serve
```

## Configuration

Site-wide settings (title, description, profile info, education, research and teaching experience) live in `_config.yml`. Blog posts go in `_posts` as Markdown files with Jekyll front matter (`layout`, `title`, `date`, `categories`, `description`, `image`).
